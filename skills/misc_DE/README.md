# Misc (DE)

Tools, die aufbewahrt werden, aber selten verwendet werden. Deutsche Übersetzungen der englischen Originale in `../misc/`.

- **[git-guardrails-claude-code_DE](./git-guardrails-claude-code_DE/SKILL.md)** — Claude-Code-Hooks einrichten, um gefährliche Git-Befehle (push, reset --hard, clean, etc.) vor ihrer Ausführung zu blockieren.
- **[migrate-to-shoehorn_DE](./migrate-to-shoehorn_DE/SKILL.md)** — Test-Dateien von `as`-Typ-Assertions zu @total-typescript/shoehorn migrieren.
- **[scaffold-exercises_DE](./scaffold-exercises_DE/SKILL.md)** — Übungsverzeichnisstrukturen mit Abschnitten, Aufgaben, Lösungen und Erklärern anlegen.
- **[setup-pre-commit_DE](./setup-pre-commit_DE/SKILL.md)** — Husky-Pre-Commit-Hooks mit lint-staged, Prettier, Typprüfung und Tests einrichten.
