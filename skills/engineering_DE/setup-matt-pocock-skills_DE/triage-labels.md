# Triage-Labels

Die Skills sprechen in Begriffen von fünf kanonischen Triage-Rollen. Diese Datei mappt diese Rollen auf die tatsächlich im Issue-Tracker dieses Repos verwendeten Label-Strings.

| Label in mattpocock/skills | Label in unserem Tracker | Bedeutung                                        |
| -------------------------- | ------------------------ | ------------------------------------------------ |
| `needs-triage`             | `needs-triage`           | Maintainer muss dieses Issue evaluieren          |
| `needs-info`               | `needs-info`             | Wartet auf Melder für mehr Informationen         |
| `ready-for-agent`          | `ready-for-agent`        | Vollständig spezifiziert, bereit für einen AFK-Agent |
| `ready-for-human`          | `ready-for-human`        | Erfordert menschliche Implementierung            |
| `wontfix`                  | `wontfix`                | Wird nicht umgesetzt                             |

Wenn ein Skill eine Rolle erwähnt (z. B. „das AFK-Ready-Triage-Label anwenden"), den entsprechenden Label-String aus dieser Tabelle verwenden.

Die rechte Spalte bearbeiten, um dem tatsächlich verwendeten Vokabular zu entsprechen.
